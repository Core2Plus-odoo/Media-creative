# C2P Creative Studio

Creative briefs, concept routes, art-direction review rounds and approvals.
See the repository README for the role matrix and the workflow rules.

Odoo 20 notes handled here: `group_expand` hooks accept any signature, the 1-5
scoring selections avoid the priority widget, sequences are drawn per company,
and every model carries a stored `company_id` behind a global multi-company
record rule.
